## 2. Previously Hardcoded / Disconnected Behaviours Repaired During Audit
1. **Fixed:** `isSolvent: true` previously did not verify the sibling path in the browser. Now `verifyMerkleSumProof()` recomputes every SHA-256 parent hash and sum up to `merkleRootHash` and rejects tampered proofs.
2. **Fixed:** `POST /api/v1/auth/login` previously switched identities without checking credentials. Now it validates passwords using `PBKDF2-SHA256` and issues signed JWTs required by all protected endpoints.
3. **Fixed:** Benchmark runs previously mutated the live demo order book. Now benchmarks execute in an isolated sandbox book (`mkt_benchmark_sandbox`) so diagnostic runs never corrupt live user trading state.
